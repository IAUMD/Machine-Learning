# Lab 4: Data Quality Assessment and Preprocessing

Performing data quality assessment and preprocessing on the `vehicles.csv` dataset using Python and Jupyter Notebook.

## Objectives

- Inspect dataset structure and data types
- Convert incorrect data types (e.g., datetime fields)
- Detect and handle missing values
  - Record removal
  - Mean imputation
  - Median imputation
- Detect and handle outliers using:
  - IQR method
  - Percentile capping
- Apply Min-Max normalization to selected numerical features

## Files

- notebook.ipynb  
  Jupyter Notebook containing all preprocessing steps

- vehicles.csv  
  Dataset used for analysis

## Technologies Used

- Python 3
- pandas
- NumPy
- scikit-learn
